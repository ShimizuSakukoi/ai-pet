# Live2D 模型文件目录
# 
# 请将你的 Live2D 模型文件放到此目录下。
# 模型文件通常包括：
#   - xxx.model3.json  (模型配置)
#   - xxx.moc3          (骨骼数据)
#   - textures/         (贴图文件夹)
#   - motions/          (动作文件)
#   - expressions/      (表情文件)
#
# 免费模型获取:
#   - Live2D Cubism SDK 自带示例模型
#   - 社区模型搜索 "free live2d model"
#
# 放入后在 ui/js/live2d.js 中修改 MODEL_PATH 为你的模型路径
